# Applied Econometrics — Exercise Solutions

Personal study notes and exercise solutions for working through the textbook:

> **Applied Econometrics** by Dimitrios Asteriou and Stephen G. Hall

## Purpose

This repository is a personal learning exercise. I'm using it to practice the concepts from the book by attempting the end-of-chapter exercises in R. The "Key Ideas" sections are my own summaries written to reinforce understanding, they are not a substitute for the textbook.
